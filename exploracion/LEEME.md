# exploracion/

Aquí guarda la app local de Atorapp (modo exploración, Fase 3F) lo que corre: una carpeta por
evaluación con `exploracion.json`, las capturas de axe y, si se exporta, `reporte.md`.

Es una **estimación experimental, no verificada con NVDA**, sin objetivo correcto fijado de antemano.
Nada de esta carpeta entra a `estudio/`, al análisis ni a `interfaz/datos.js`. No se versiona (ver
`.gitignore`), salvo este archivo.
